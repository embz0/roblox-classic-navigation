# Changelog

All notable changes to this project are documented here.

## [2.0.0] - 2026-09-22

- Rebuilt the classic navigation around Roblox’s live sidebar data.
- Added dynamic account header, badges, promotional cards, extension sections, and theme syncing.
- Preserved the separate Profile navigation entry.
- Reduced observer work by using a visible-data signature and debounced rebuilds.
- Added a public repository structure, documentation, and contribution workflow.
